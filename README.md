## AI Prompt Library
A set of prompt-generators designed to help with the maintenance of Wikipedia pages - mainly for songs and albums.

## Prompts
Infobox Generation
* Song Infobox Prompt Generator: Populates a song infobox using reliable sources. (<a href="#" title="I typically use 3-5 different AI tools and compare the results and check sources cited. Do not trust the robots! 😃">note</a>)

Source Identification
* Song Notability Identifier: Finds potential sources to establish song notability.
* Album Notability Identifier: Finds potential sources to establish album notability.
* General Notability Identifier: Finds potential sources to establish notability about any topic.

Image Find
* Song Image Finder: Identifies potential images for a song article.
